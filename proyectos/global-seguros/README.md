<h2>Descripción del Proyecto</h2>  

<p> Global Seguros Colombia es una plataforma web diseñada para ofrecer información <br>
y adquisición de seguros educativos de manera rápida, segura y accesible. <br>
El sitio está dirigido a padres de familia, estudiantes y personas interesadas <br>
en proteger la educación de sus hijos mediante planes de ahorro y protección   <br>
financiera.<br>
  <br>
La página permite visualizar información detallada sobre los servicios ofrecidos <br>
por la aseguradora, consultar beneficios, registrar usuarios, cotizar productos y <br>
realizar pagos en línea mediante diferentes métodos de pago. Además, incorpora <br>
validaciones de formularios para garantizar la integridad de los datos ingresados <br>
por los usuarios. <br>
  <br> 
Como reto adicional, se desarrolló una tienda virtual integrada donde los usuarios   <br>
pueden explorar productos relacionados con la marca y realizar compras de forma   <br>
segura. Para la implementación se utilizaron tecnologías web como HTML, CSS y   <br>
JavaScript, organizando el proyecto de forma modular para facilitar su <br>
mantenimiento y escalabilidad. </p>
