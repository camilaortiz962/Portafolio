## ◈ SOBRE MÍ

Soy **Creadora Digital**, interesada en la unión entre el **diseño, la tecnología y la narrativa visual**.

Mi trabajo busca transformar ideas en experiencias digitales que combinen **estética, funcionalidad e interacción**.

Me interesa desarrollar proyectos desde una perspectiva tanto creativa como técnica, buscando que cada propuesta no solo tenga una identidad visual atractiva, sino que también sea funcional y significativa para quienes la utilizan.
