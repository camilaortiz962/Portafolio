# Avatar guía

Añade aquí el avatar que acompañará la navegación del portafolio.

Archivos esperados:

- `camila-avatar.glb`: modelo de cuerpo completo listo para web, con materiales incorporados.
- `camila-avatar-idle.glb`: variante con animación de reposo, si se exporta por separado.
- `avatar-front.webp`, `avatar-3quarter.webp` y `avatar-back.webp`: renders ligeros de respaldo.
- `animations/`: clips `.glb` o `.fbx` exportados para saludo, caminar o señalar, si el desarrollo los requiere.

El modelo debe conservar el mismo vestuario y proporciones en toda la experiencia. Se recomienda un rig humanoide, materiales optimizados y sin objetos fijos en las manos.
