# Escenarios 3D

Añade aquí los espacios que enmarcan cada capítulo de la experiencia.

Archivos sugeridos:

- `studio.glb`: introducción y manifiesto.
- `gallery.glb`: proyectos destacados.
- `laboratory.glb`: proceso y especialidades.

Si un escenario es pesado, divídelo por secciones o utiliza iluminación y geometrías sencillas generadas en código. Exporta versiones optimizadas para navegador.
