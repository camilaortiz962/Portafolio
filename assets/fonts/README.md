# Tipografías

Añade aquí únicamente archivos de fuente con licencia para uso web (`.woff2` preferiblemente). Incluye las variantes que se vayan a utilizar, por ejemplo:

- `display-regular.woff2`
- `display-bold.woff2`
- `body-regular.woff2`
- `body-medium.woff2`

Si la tipografía se carga desde un proveedor externo autorizado, conserva aquí una nota con el nombre de la familia y la licencia, en lugar de copiar archivos sin permiso.
