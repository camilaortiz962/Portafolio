# Recursos del nuevo recorrido de proyectos

Esta carpeta será para los recursos que el rediseño 3D necesita por proyecto. No reemplaza `assets/proyectos/`, que contiene el material ya utilizado por el sitio actual.

Organización sugerida:

```text
projects/
  nombre-del-proyecto/
    cover.webp
    gallery-01.webp
    video.mp4
    project-object.glb
```

Usa nombres en minúsculas, sin espacios ni acentos, y formatos web comprimidos. Añade solamente recursos que vayan a formar parte de la nueva experiencia.
