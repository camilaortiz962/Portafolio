# Texturas

Guarda aquí texturas optimizadas para los modelos y los fondos del recorrido: `noise.webp`, `grain.webp`, mapas PBR (`basecolor`, `normal`, `roughness`, `metallic`) y HDRI ligeros cuando sean necesarios.

Conviene usar `.webp`, `.jpg` o `.ktx2` según el recurso. Nombra los mapas con el mismo prefijo del modelo para mantenerlos identificables.
