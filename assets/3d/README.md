# Objetos 3D

Coloca aquí modelos web en `.glb` o `.gltf` para representar las disciplinas y el proceso creativo.

Primer conjunto recomendado:

- `magazine.glb`
- `monitor.glb`
- `package.glb`
- `camera.glb`
- `frame.glb`
- `abstract-object.glb`

Cada archivo debe estar optimizado para tiempo de carga, con geometría limpia, texturas comprimidas y escala coherente. Conserva los archivos fuente fuera de esta carpeta pública.
