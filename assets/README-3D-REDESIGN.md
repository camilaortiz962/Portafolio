# Recursos para el rediseño 3D

Esta guía acompaña el rediseño integral del portafolio. Las carpetas y archivos que ya existían en `assets/` se conservan sin cambios; estos recursos nuevos se añaden en paralelo.

## Entregables pendientes

- `avatar/`: modelo principal de María Camila en formato `.glb`, con rig y animaciones opcionales, además de renders de respaldo.
- `3d/`: objetos de escena en `.glb` o `.gltf` (revista, monitor, empaque, cámara, marco y objeto abstracto).
- `environments/`: escenarios 3D optimizados (estudio, galería y laboratorio).
- `projects/`: imágenes, videos y, cuando corresponda, modelos específicos de cada proyecto para la nueva narrativa 3D. Los proyectos actuales permanecen en `proyectos/` y `assets/proyectos/`.
- `textures/`: texturas PBR y recursos visuales ligeros.
- `icons/`: iconos SVG propios o con licencia compatible.
- `fonts/`: archivos tipográficos con licencia web o las indicaciones de carga desde una fuente autorizada.

Antes de publicar, comprime los modelos y texturas para web; evita guardar archivos fuente pesados como `.blend`, `.psd` o `.ai` en la carpeta pública.
