# Iconos

Coloca aquí iconos en SVG para navegación, redes, controles de sonido, cerrar, flechas y acciones de la escena. Utiliza iconos propios o recursos cuya licencia permita su uso en el portafolio.

Mantén los SVG limpios y con un `viewBox` definido; evita convertirlos en imágenes rasterizadas salvo que sea imprescindible.
